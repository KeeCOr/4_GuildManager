# GuildManager Living Room Mercenaries Design

## Goal
건물 안에 배치된 대기중 용병들이 전체 장면에서도 계속 움직이고, 방 위치에 맞는 행동을 반복하도록 만든다.

## Selected Approach
좌표 프리셋과 CSS 루프 애니메이션을 사용한다. 저장 데이터는 변경하지 않고, 현재 `mercs`, `room`, `status`, `pendingMercIds`에서 화면용 에이전트 목록을 파생한다.

## Behavior
- `대기중`이고 퀘스트 대기열에 없는 용병만 건물 생활 레이어에 표시한다.
- `길드마스터룸` 용병은 책상/전략 테이블 주변에서 보고/대기 동작을 한다.
- `훈련소` 용병은 더미/표적/무기 거치대 주변에서 훈련 동작을 한다.
- `식당` 용병은 테이블/카운터 주변에서 서빙/식사 동작을 한다.
- 각 용병은 id 기반 해시로 안정적인 위치/타이밍/행동 슬롯을 배정받아 리렌더 후에도 튀지 않는다.
- 전체 장면에서도 작게 보이고, 확대 시 자연스럽게 커진다.
- 클릭하면 기존 `roomMercPreview` 상세 모달을 연다.

## Constraints
- Save schema 변경 없음.
- 신규 런타임 의존성 없음.
- 기존 드래그 앤 드롭 방 배치와 퀘스트 배치 흐름 유지.
- 전경 소품 레이어보다 낮은 기본 z-index를 쓰되, y좌표 기반으로 깊이감을 준다.

## Testing
- `npm run build`로 TypeScript/Vite 빌드 검증.
- 수동 확인: 기본 전체 장면에서 방별 용병이 움직임, 확대 보기에서도 클릭/방 선택/드래그 대상이 깨지지 않음.
