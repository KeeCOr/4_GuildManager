# GuildManager — Steam 스토어 설명 (한국어)

## 짧은 설명 (30자)
중세 용병 길드를 운영하라. 모집, 훈련, 전투 파견으로 전설적인 전쟁 회사를 키워나가세요.

## 전체 설명

**GuildManager**는 중세 용병 회사의 수장이 되는 전략 관리 게임입니다.

다양한 배경을 가진 전사들을 고용하고, 훈련시키고, 계약 임무에 파견하세요. 사기와 임금을 관리하며 지역 전체에 걸쳐 길드의 명성을 쌓아 올리세요.

**주요 특징:**
- **길드 관리** — 용병단 구성원 채용, 해고, 훈련, 장비 관리
- **전술 전투** — 수제작 맵에서 펼쳐지는 턴제 전투
- **명성 시스템** — 길드 명성이 새로운 계약 등급과 클라이언트 관계를 열어줌
- **로그라이트 진행** — 각 캠페인 런마다 다른 용병, 계약, 이벤트 제공
- **어드바이저 시스템** — AI 어드바이저가 핵심 결정 사항과 전략 옵션 제안
- **다양한 빌드** — 클래스 특화와 장비 조합으로 수백 가지 유효한 부대 구성 가능

---

## 게임 소개

GuildManager는 **전투 이전**의 의사결정 — 인사 결정, 계약 수락, 자원 배분 — 이 전투 자체만큼 만족스럽기를 원하는 고전 전략 게임 팬들을 위한 프로젝트로 시작되었습니다.

모든 채용은 리스크입니다. 모든 계약은 트레이드오프입니다. 모든 손실은 아픕니다.

---

## 시스템 요구사항

**최소:**
- OS: Windows 10 (64비트)
- 프로세서: Intel Core i5 / AMD Ryzen 5
- 메모리: 4 GB RAM
- 그래픽: DirectX 11 지원 내장 그래픽
- 저장공간: 200 MB

**권장:**
- OS: Windows 11 (64비트)
- 프로세서: Intel Core i7 / AMD Ryzen 7
- 메모리: 8 GB RAM
- 저장공간: 500 MB
